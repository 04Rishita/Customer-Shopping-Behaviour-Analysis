# 🛍️ Customer Shopping Behaviour Analysis

## 📌 Project Overview

**Customer Shopping Behaviour Analysis** is an end-to-end data analytics project focused on understanding customer purchasing patterns, product preferences, spending behaviour, customer segments, and sales trends.

The project uses **Python, SQL, Power BI/visualization, and Streamlit** to transform raw customer shopping data into meaningful business insights.

The complete workflow includes data cleaning, exploratory data analysis, SQL-based business analysis, visualization, dashboard development, and insight generation.

---

# 🎯 Project Objectives

The main objectives of this project are:

* Understand customer purchasing behaviour.
* Analyze customer demographics and shopping patterns.
* Identify high-performing product categories.
* Analyze customer spending and purchase amounts.
* Study the impact of discounts on purchasing behaviour.
* Analyze customer subscription behaviour.
* Identify repeat and loyal customers.
* Compare purchasing behaviour across different customer segments.
* Identify important business trends and patterns.
* Create interactive dashboards for better decision-making.

# 🧹 Data Cleaning & Preprocessing

The raw customer shopping dataset was first examined and prepared for analysis.

### Major preprocessing steps:

* Checked dataset structure and dimensions.
* Identified missing values.
* Handled missing values where required.
* Checked and corrected data types.
* Identified duplicate records.
* Checked inconsistent categorical values.
* Standardized column values.
* Created additional analytical features.
* Prepared the cleaned dataset for SQL and visualization.

The cleaned dataset was then used for further analysis and dashboard development.
